어디갔지 (MEmory)

방문한 장소, 다가올 약속, 매일의 루틴을 기록하는 일상 아카이브

📖 자주 묻는 질문

어떤 앱인가요?

'어디갔지'는 다녀온 장소, 앞으로의 약속, 매일의 루틴, 그리고 일기를 한 곳에 기록할 수 있는 일상 아카이브 앱입니다. 외출 모드와 홈 모드를 구분해 집 밖과 집 안의 시간을 모두 담을 수 있습니다.

로그인이 필요한가요?

아니요. 어디갔지는 별도의 회원가입이나 로그인 없이 사용할 수 있습니다. 모든 기록은 이용자의 기기 안에만 저장됩니다.

내 데이터는 어디에 저장되나요?

모든 기록은 이용자의 기기 내부에만 저장됩니다. 외부 서버로 전송되거나 다른 사람에게 공유되지 않습니다. 앱을 삭제하면 저장된 모든 정보도 함께 삭제됩니다.

지도 검색이 작동하지 않아요.

지도 검색 기능은 카카오 지도 API를 사용합니다. 이 기능을 사용하려면 카카오 개발자센터에서 발급받은 인증키를 앱에 입력해야 합니다. 키를 입력하지 않으면 장소를 직접 텍스트로 입력해서 기록할 수 있습니다.

카카오 지도 API 키는 어떻게 발급받나요?

카카오 개발자센터에서 무료로 발급받을 수 있습니다. 아래 절차를 따라 진행해 주세요.

  1. 카카오 개발자센터(developers.kakao.com) 접속 후 카카오 계정으로 로그인
  2. 상단 메뉴에서 '내 애플리케이션' → '애플리케이션 추가하기' 클릭
  3. 앱 이름, 사업자명 입력 후 저장 (개인 사용이면 본인 이름 입력)
  4. 생성된 앱의 '앱 키' 메뉴에서 REST API 키 또는 네이티브 앱 키 확인
  5. 발급받은 키를 어디갔지 앱의 설정 화면에 붙여넣기

키 발급은 무료이며, 개인 용도라면 별도 비용이 발생하지 않습니다.

외출 모드와 홈 모드는 무엇인가요?

외출 모드는 집 밖에서의 활동(다녀온 장소, 만남, 외부 일정)을, 홈 모드는 집 안에서의 시간(휴식, 루틴, 집안일 등)을 기록하는 모드입니다. 두 모드를 따로 보거나 통합해서 한 번에 볼 수 있어 일과 휴식을 균형 있게 돌아볼 수 있습니다.

일기는 어떻게 생성되나요?

하루 동안 기록한 장소, 약속, 루틴 등을 모아 자동으로 일기 형태로 정리해드립니다. 직접 글을 쓰지 않아도 그날의 흐름을 한눈에 볼 수 있습니다.

기록한 데이터를 백업할 수 있나요?

현재는 기기 내부 저장만 지원합니다. 백업 기능은 추후 업데이트에서 검토 중입니다. 새 기기로 옮기시기 전에는 데이터 이전이 어려우니 참고 부탁드립니다.

알림은 어떻게 설정하나요?

앱 첫 실행 시 알림 권한을 허용하시거나, iOS의 설정 → 어디갔지 → 알림 메뉴에서 언제든 켜고 끌 수 있습니다.

아래 이메일로 발견하신 내용을 보내주시면 빠르게 확인하고 다음 업데이트에 반영하겠습니다. 가능하면 사용 중인 iOS 버전, 기기 모델, 문제 발생 화면 캡처를 함께 보내주시면 도움이 됩니다.
