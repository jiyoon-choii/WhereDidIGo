본 개인정보처리방침은 "어디갔지"(이하 "본 앱")이 이용자의 정보를 어떻게 처리하는지를 안내합니다. 본 앱은 별도의 서버나 사용자 계정을 운영하지 않으며, 이용자가 만든 모든 데이터는 이용자의 기기 안에만 저장됩니다. 개발자는 이용자의 어떠한 데이터도 수집·수신하지 않습니다.

2. 기기 권한

아래 권한은 이용자가 해당 기능을 직접 사용할 때만 동작하며, 자동·백그라운드 접근은 없습니다.

  • 사진 라이브러리(읽기/저장): 기록에 사진을 첨부하거나, 만든 기록 이미지를 사진 보관함에 저장할 때만 사용.
  • 카메라: 기록에 사진을 직접 촬영해 첨부하기로 선택했을 때만 사용. 촬영 사진은 앱 샌드박스에만 저장.
  • 위치(사용 중에만): 장소 검색 시 "내 주변" 결과의 정확도를 높이는 선택 보조 기능. 위치를 거부·비활성해도 앱은 정상 동작하며(한국 전역으로 검색), 위치는 즉시 사용만 하고 저장·전송하지 않습니다. 백그라운드 위치·추적·위치 로그는 없습니다.

알림, 연락처, 마이크, 백그라운드 모드 권한은 사용하지 않습니다.

3. 외부 서비스 통신 안내

본 앱은 아래의 경우에만 외부와 통신하며, 이때 전송되는 정보는 개발자가 수신하지 않습니다.

  • 외부 길찾기 등 링크는 본 앱이 아니라 기기의 시스템 브라우저에서 열립니다.

4. 데이터 내보내기·백업

이용자는 자신의 기록을 직접 내보내거나 백업할 수 있습니다.

  • 내보내기/백업 파일(사진 포함)은 기기 내부에서 생성되어 iOS 시스템 공유 시트를 통해서만 전달됩니다. 보낼 곳은 전적으로 이용자가 선택합니다.
  • 본 앱은 어떤 데이터도 자동으로 클라우드나 외부 서버에 업로드하지 않습니다.

5. 보관 및 파기

  • 모든 정보는 이용자의 기기 내부에만 저장됩니다.
  • 이용자가 앱을 삭제하면 저장된 모든 정보가 함께 삭제됩니다.
  • 본 앱은 별도의 서버를 두지 않으므로 외부에 정보가 보관되지 않습니다.

6. 제3자 제공 및 국외 이전

본 앱은 이용자의 개인정보를 제3자에게 제공하지 않으며, 국외로 이전하지 않습니다. (외부 지도·날씨 서비스 통신은 위 3항의 즉시 조회에 한합니다.)
