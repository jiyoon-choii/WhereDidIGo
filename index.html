개인정보처리방침

앱 이름: 어디갔지 (MEmory)
시행일: 2026년 5월 14일 · 최종 수정일: 2026년 5월 14일

본 개인정보처리방침은 "어디갔지"(이하 "본 앱")이 이용자의 개인정보를 어떻게 수집·이용·보관·파기하는지에 관한 사항을 안내합니다. 본 앱은 이용자의 개인정보를 소중히 다루며, 개인정보보호법 등 관련 법령을 준수합니다.

1. 수집하는 개인정보 항목

본 앱은 서비스 제공을 위해 아래의 정보를 수집할 수 있습니다.

가. 이용자가 직접 입력하는 정보

  • 닉네임: 앱 내 표시 목적

나. 자동으로 수집되는 정보

  • 자동으로 수집되는 정보는 없습니다. 본 앱은 분석 도구·광고 SDK·추적 기술을 사용하지 않습니다.

다. 기기 권한을 통해 접근하는 정보

  • 카메라: 기록에 첨부할 사진을 직접 촬영할 때만 사용 (선택)
  • 사진(라이브러리): 기록에 첨부할 사진 선택 및 캡처 이미지 저장 (선택)
  • 위치 정보(사용 중에만): 장소 검색 시 "내 주변" 결과의 정확도 향상에만 즉시 사용되며, 저장·전송되지 않습니다. 권한을 허용하지 않아도 앱은 정상 동작합니다. (선택)
본 앱은 별도의 서버를 운영하지 않으며, 위 정보는 이용자의 기기 내에만 저장됩니다. 외부 서버로 전송되거나 제3자에게 제공되지 않습니다.

라. 외부 서비스 이용에 관한 안내 (장소 검색)

본 앱의 장소 검색은 다음 외부 서비스를 이용합니다. 어느 경우든 이용자가 검색어를 입력했을 때만 호출되며, 본 앱 운영자는 해당 통신 내용을 수집·저장하지 않습니다.

  • Apple 지도(MapKit) — 기본 장소 검색·자동완성. Apple 프레임워크를 통해 처리되며 별도 키 입력이 필요 없습니다. 처리는 Apple 개인정보처리방침을 따릅니다.
  • OpenStreetMap(Nominatim) — 폴백 지오코딩. 사용 시 결과 화면에 "장소 데이터 © OpenStreetMap contributors" 저작자 표시가 노출됩니다.
  • 카카오 지도(Kakao Map) API — 선택 기능. 이용자가 본인 명의로 직접 발급받은 카카오 개발자 인증키를 앱에 입력한 경우에만 동작하며, 이때 검색어 등은 이용자 본인의 인증키를 통해 카카오로 직접 전송됩니다(운영자 미관여). 처리는 카카오 개인정보처리방침 및 약관을 따릅니다.

2. 개인정보의 이용 목적

수집된 정보는 다음 목적으로만 이용됩니다.

  • 앱 내 기록(장소·약속·루틴·일기) 작성·관리 기능 제공
  • 장소 검색 결과의 정확도 향상
  • 서비스 이용에 관한 안내

3. 개인정보의 보관 및 파기

  • 모든 정보는 이용자의 기기 내부에만 저장됩니다.
  • 이용자가 앱을 삭제하면 저장된 모든 정보가 함께 삭제됩니다.
  • 본 앱은 별도의 서버를 두지 않으므로 외부에 정보가 보관되지 않습니다.

4. 개인정보의 제3자 제공

본 앱은 이용자의 개인정보를 제3자에게 제공하지 않습니다.

5. 개인정보의 국외 이전

본 앱은 개인정보를 국외로 이전하지 않습니다.

6. 이용자의 권리

  • 기기 설정에서 카메라, 사진, 위치 권한 변경·철회
  • 앱 삭제를 통한 모든 정보의 일괄 삭제
